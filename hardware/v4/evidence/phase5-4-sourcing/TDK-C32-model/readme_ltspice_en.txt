[How to use the files with LTspiceXVII]
- This library includes two types of files.
   *.asy : symbol file
   *.mod : netlist file
- Save files at one of the following directories;
   1)Save both asy and mod file at the directory where intended
     simulation circuit is saved
     In this case, the model can be used only in the simulation circuits
     saved at the same directory
   2)Save asy file at C:/Users/<UserName>/Documents/LTspiceXVII/lib/sym
     Save mod file at C:/Users/<UserName>/Documents/LTspiceXVII/lib/sub
     In this case, the model can be used in all the simulation circuits
- Please visit the following URL for more detailed information.
  https://product.tdk.com/info/en/technicalsupport/tvcl/index.html
