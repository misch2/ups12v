## Permanent tooling

Added **`hardware/v4/tools/`** with an explicit CLI, short README, five focused modules and a standard-library regression suite. Geometry snapshot/type dispatch, route creation, native save/reload and preservation logic were extracted from the working Phase4.7 helpers, not replaced with another independent diagnostic implementation. The CLI and package are import-safe and have no module-level CAD loading, process launch or evidence reads/writes. Native pcbnew import is lazy and occurs only in the isolated worker.

- `geometry.py`: stable UUID inventories, track geometry, via positions/drills/per-layer widths, native pad polygons and drill dimensions, footprint metadata, filled-zone snapshots, preservation comparisons. Via handling precedes PCB_TRACK; unsupported arc-track input fails closed rather than silently losing geometry. Current V4 scope is four copper layers and straight tracks/through-via route creation.
- `safety.py`: exact source hashes, fresh resolved scratch paths outside production, copied project/schematic/rules checks, scratch lock detection and monitored native workers. Production is never loaded by native code: only an isolated byte-copy is loaded. Before saves and checks, hashes/locks are rechecked. No automatic editor interaction or IPC fallback.
- `native.py`: copied plan application, one explicitly identified original layer change, native scratch save/reload, comparison of all original geometry covered by the snapshot and independent expected-vs-readback comparison of every added route/via.
- `checks.py`: complete configured native DRC with refill/connectivity/parity, optional ERC, strict structured JSON parsing. Missing report fields/coverage cannot become zero findings. Unconnected items, warnings and inherited ignored checks remain explicit.
- `cli.py`, `kicad_v4.py`: explicit board/manifest/plan/UUID/layers/native executable/output-directory arguments. No production save command or component movement operation. Native workers stop on assertion/IPC diagnostics, including the exact earlier assertion and connection-refused text, preserve full logs and require owner recovery approval; only their own child process is terminated.

The three active old layer-validation/geometry/width-smoke helpers now forward to the toolkit CLI with explicit arguments. Their duplicated native geometry implementations and import-time execution were removed. Other evidence helpers remain historical artifacts and are not used by this workflow. Added AGENTS.md tooling rules requiring future native V4 work to reuse this toolkit and its guards/tests.

No commit or push was made. Toolkit source and tests are reviewable project files; generated bytecode is ignored. README documents interfaces, mm units, schema version1, plan structure, limitations and maintenance commands.
