L1977@P32: 10.2.2.10 Feedforward Capacitor CFF Selection
L1978@P32: In some cases, a feedforward capacitor can be used across RFBT to improve the load transient response or
L1979@P32: improve the loop phase margin. This is especially true when values of RFBT > 100 kΩ are used. Large values
L1980@P32: of RFBT in combination with the parasitic capacitance at the FB pin can create a small signal pole that interferes
L1981@P32: with the loop stability. A CFF helps mitigate this effect. Use lower values to determine if any advantage is gained

L1986@P32: 10.2.2.11 Maximum Ambient Temperature
L1987@P32: As with any power conversion device, the TPS6293x dissipates internal power while operating. The effect of
L1988@P32: this power dissipation is to raise the internal temperature of the converter above ambient. The internal die
L1989@P32: temperature (TJ) is a function of the following:
L1990@P32: • Ambient temperature
L1991@P32: • Power loss
L1992@P32: • Effective thermal resistance, RθJA, of the device
L1993@P32: • PCB combination
L1994@P32: The maximum internal die temperature must be limited to 150°C. This establishes a limit on the maximum
L1995@P32: device power dissipation and, therefore, the load current. Equation 24 shows the relationships between the
L1996@P32: important parameters. It is easy to see that larger ambient temperatures (TA) and larger values of RθJA reduce
L1997@P32: the maximum available output current. The converter efficiency can be estimated by using the curves provided in
L1998@P32: this data sheet. Note that these curves include the power loss in the inductor. If the desired operating conditions
L1999@P32: cannot be found in one of the curves, then interpolation can be used to estimate the efficiency. Alternatively, the
L2000@P32: EVM can be adjusted to match the desired application requirements and the efficiency can be measured directly.
L2001@P32: The correct value of RθJA is more difficult to estimate. As stated in the Semiconductor and IC Package Thermal

L2261@P38: If the converter is connected to the input supply through long wires or PCB traces, special care is required to
L2262@P38: achieve good performance. The parasitic inductance and resistance of the input cables can have an adverse
L2263@P38: effect on the operation of the converter. The parasitic inductance, in combination with the low-ESR, ceramic
L2264@P38: input capacitors, can form an under-damped resonant circuit, resulting in overvoltage transients at the input to
L2265@P38: the converter. The parasitic resistance can cause the voltage at the VIN pin to dip whenever a load transient
L2266@P38: is applied to the output. If the application is operating close to the minimum input voltage, this dip can cause
L2267@P38: the converter to momentarily shutdown and reset. The best way to solve these kind of issues is to reduce the
L2268@P38: distance from the input supply to the converter and use an aluminum or tantalum input capacitor in parallel with
L2269@P38: the ceramics. The moderate ESR of these types of capacitors help damp the input resonant circuit and reduce
L2270@P38: any overshoots. A value in the range of 20 μF to 100 μF is usually sufficient to provide input damping and help
L2271@P38: hold the input voltage steady during large load transients.
L2272@P38: TI recommends that the input supply must not be allowed to fall below the output voltage by more than 0.3
L2273@P38: V. Under such conditions, the output capacitors discharges through the body diode of the high-side power
L2274@P38: MOSFET. The resulting current can cause unpredictable behavior, and in extreme cases, possible device
L2275@P38: damage. If the application allows for this possibility, then use a Schottky diode from VIN to VOUT to provide a
L2276@P38: path around the converter for this current.
L2277@P38: In some cases, a transient voltage suppressor (TVS) is used on the input of converters. One class of this
L2278@P38: device has a snap-back characteristic (thyristor type). The use of a device with this type of characteristic is not
L2279@P38: recommended. When the TVS fires, the clamping voltage falls to a very low value. If this voltage is less than the
L2280@P38: output voltage of the converter, the output capacitors discharges through the device, as mentioned above.
